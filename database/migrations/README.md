# Migrations PostgreSQL

Emplacement des migrations versionnées : `database/migrations/`.

**Existant** : exécuteur `bin/migrate` (`php bin/migrate`, `php bin/migrate status`) et table de suivi `schema_migrations`; migration `0001_tasks_and_dependencies.sql` (tâches, dépendances, trigger anti-cycle), `0002_task_status.sql` (colonnes `status`, défaut `todo`, et `completed_at`, deux `CHECK`; additive, les tâches existantes passent à `todo` sans clôture) et `0003_task_project_conclusions.sql` (colonnes `project`, liste fermée par `CHECK tasks_project_valid`, et `conclusions`, nullables; additive, les tâches existantes reçoivent `NULL`), appliquées en local et en test seulement. Refus si `APP_ENV` n’est ni `local` ni `test` (sauf `--allow-env=<APP_ENV>`, uniquement avec autorisation explicite). Conception : [docs/architecture.md](../../docs/architecture.md), section « Cycle de vie ».

**`0003`** : conception validée par l'utilisateur (section « Champs "Projet" et "Conclusions" » de [docs/architecture.md](../../docs/architecture.md)); suite de tests OK sur PostgreSQL 17 local (rapporté par le Developer). **Non vérifié** : PostgreSQL 16 et 18, AlwaysData (aucune migration appliquée).

**Retour arrière de `0003`** : pas de « down »; restauration d'une sauvegarde, ou migration `0004` (`DROP COLUMN`) destructive, sur décision de l'utilisateur seulement.

**`0004_projects.sql` (validé par l'utilisateur le 2026-10-15; écrite le 2026-10-15; appliquée sur la base locale seulement, voir CHANGELOG)** : crée `projects` (index unique sur `lower(name)`; six projets : `MS-HR` Pro, `Jardin/Maison`, `OPF`, `Erendil` Perso, accueils « Divers Pro » et « Divers Perso »), rattache chaque tâche à un projet (`tasks.project_id`, clé étrangère `ON DELETE RESTRICT`) et supprime `tasks.category` et `tasks.project`. Rapport : `src/Infrastructure/ProjectConflictReport.php`, lancé par `bin/report-project-conflicts` (code de sortie 0 sans conflit, 1 sinon, refus si `projects` existe déjà). Procédure validée : (1) sauvegarde `pg_dump`; (2) `php bin/report-project-conflicts` (lecture seule, validé) : liste les tâches dont la catégorie diffère de celle de leur projet; (3) arbitrage manuel des conflits; (4) `php bin/migrate` : s'arrête sans état partiel et liste les conflits s'il en reste; (5) vérification : six projets, aucune tâche sans `project_id`. Local et test seulement; aucune migration AlwaysData sans autorisation explicite. **Non vérifié** : exécution de `0004` sur PostgreSQL 16, 17, 18 et AlwaysData (droits, pgBouncer, `LC_CTYPE`). Le message `RAISE` de la garde (nombre et liste des conflits) est vérifié côté PDO sur PostgreSQL 17 local. Conception : section « Projets configurables » de [docs/architecture.md](../../docs/architecture.md).

**`0005_task_importance.sql` (validée le 2026-10-17 et livrée en local; écrite le 2026-10-17; appliquée sur les bases locales seulement, jamais sur AlwaysData; voir CHANGELOG)** : ajoute `tasks.importance` (`text NOT NULL DEFAULT 'Mineure'`, `CHECK tasks_importance_valid` sur `Mineure`/`Majeure`/`Critique`); additive, toutes les tâches existantes passent à `Mineure`, sans `UPDATE`. Procédure prévue : sauvegarde `pg_dump` hors local, `php bin/migrate`, vérification (aucune tâche sans importance, trois valeurs seules). Local et test seulement; aucune migration AlwaysData sans autorisation explicite. Vérifiée sur PostgreSQL 17 local (745 tests OK, rapporté par le Developer). **Non vérifié** : PostgreSQL 16 et 18, AlwaysData (droit `ALTER TABLE`, pgBouncer); aucune application sur AlwaysData. Conception : section « Importance d'une action » de [docs/architecture.md](../../docs/architecture.md).

**Validé** (voir [docs/architecture.md](../../docs/architecture.md)) : fichiers SQL `NNNN_description.sql` appliqués dans l’ordre par `bin/migrate`, table de suivi `schema_migrations` avec checksum, transaction par migration, pas de migration « down ». Une migration appliquée n’est jamais réécrite : toute correction passe par une nouvelle migration. Ne jamais lancer une migration sur un environnement opérationnel sans autorisation explicite.
